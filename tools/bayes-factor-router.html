What this tool does

      
Given a Bayes factor BF comparing two hypotheses (e.g., H1: gravitational wave background vs. H0: noise), or its log-scale 2·ln BF, this tool classifies the evidence strength using the Jeffreys (1961) / Kass & Raftery (1995) thresholds and returns a routing token for use in ChainGraph evidence chains.

      
Scales

      
    
        
  • BF < 1 — supports null hypothesis
    • 
        
  • 1 ≤ BF < 3.2 — weak (barely worth mentioning)
    • 
        
  • 3.2 ≤ BF < 10 — substantial
    • 
        
  • 10 ≤ BF < 100 — strong
    • 
        
  • BF ≥ 100 — decisive
    • 
      

      
Worked example

      
NANOGrav 15-year data set (arXiv:2306.16213) reports BF > 10¹⁴ for the gravitational wave background, classifying as decisive evidence.
